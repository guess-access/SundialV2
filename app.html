          Schedule

          Times are Eastern (EST), written like 9:00 AM to 6:00 PM. Every day can be different — fixed hours, a split shift, flexible hours or a rest day.

          Import people and schedules

          One person per row, in this column order — a header row is optional:
          name, username, passcode, role, mon, tue, wed, thu, fri, sat, sun, schedule_from Each day is a shift like 9:00 AM-6:00 PM (Eastern) or 10:00 PM-6:00 AM, or off / Rest day for a day off. Two shifts in one cell keep both windows, e.g. 8:00 AM-12:00 PM + 1:00 PM-5:00 PM. Write Flexible for a day with no fixed hours. Leave every day blank (or write Executive) for no fixed schedule. Comma or tab separated both work. schedule_from is optional — it is the date the roster starts (like 2026-10-05), so weekly changes can be kept one per week; leave it out and today's date is used. Leave the passcode blank and one gets generated. An existing username is updated, not duplicated. Every time on this site is Eastern (EST).
